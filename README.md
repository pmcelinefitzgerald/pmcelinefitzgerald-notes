# pmcelinefitzgerald-notes

Product manager · B2B dev tools

学习用的示例项目

## 用法

```bash
cat data.txt | go run main.go
```

输出：

```
   3  error: timeout
   1  warn: retry
---

```

## 安装

```bash
git clone https://github.com/USER/pmcelinefitzgerald-notes.git
cd pmcelinefitzgerald-notes
go build ./...
```
